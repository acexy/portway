# Portway 未来计划

本文档概述 Portway 未来可能探索的方向。这些内容尚未纳入已确认范围，
不构成实现或发布日期承诺。

## UDP 强化

- 增加可复现的丢包、拥塞、队列溢出和高来源基数负载场景测试。
- 增加长时间运行的关联过期和资源趋势验证。
- 评估原生 QUIC Datagram 支持是否能带来足够的收益，以证明额外传输能力的必要性。

## 性能

- 建立可复现的 TCP、HTTP、HTTPS、UDP 和传输基准测试。
- 在持续负载下分析 CPU、内存分配、goroutine 和文件描述符。
- 在经过验证的热路径中减少可避免的分配和拷贝。
- 根据实测结果调优 HTTP 连接复用和链路调度。
- 仅在基准测试证明有实际收益时评估缓冲区复用、池化和多路复用。
- 记录典型部署规模下的容量预期。

## 稳定性与缺陷修复

- 持续修复正确性、兼容性和资源生命周期相关的缺陷。
- 扩展竞态检测器、模糊测试、故障注入和长时间运行测试的覆盖范围。
- 验证在丢包和网络中断情况下的重连与恢复行为。
- 提高畸形输入和协议状态的测试覆盖率。
- 维护 Linux、macOS 和 Windows 的发布兼容性。
- 保持依赖项、运维文档和安全指南的及时更新。

## 运维成熟度

- 增加健康检查、就绪检查和指标端点。
- 定义稳定的运维指标和日志字段。
- 增加可复现的负载和长时间浸泡测试场景。
- 改进发布验证、升级指导和回滚流程。

## 贡献指南

缺陷报告应包含 Portway 版本、操作系统、所选传输方式、相关代理类型、最小复现步骤
以及已脱敏的日志。切勿包含 Token、私钥、含私钥材料的证书或业务流量。

安全问题必须遵循[安全文档](../security/README_ZH.md)中描述的私有报告流程。
